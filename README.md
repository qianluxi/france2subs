# france2subs

下载 france.tv 视频，并自动生成**法语 / 中文 / 中法双语**字幕的小工具。

面向普通用户：粘贴网址 → 点一下 → 得到视频 + 字幕，全程本地运行、免费、无广告。

当前版本：**v1.1.0**（新增字幕时间轴对齐机制，修复长视频中段字幕脱节）

## 功能

- 下载 france.tv 视频（最高 1080p，自动合并音视频）
- 法语语音识别（本地 Whisper large-v3-turbo 模型）
- 中文翻译（本地 Argos 模型，法→英→中，纯离线）
- **字幕时间轴自动对齐**：检测音轨 PTS 断口并补齐，长视频从片头到片尾不漂移
- 输出多种字幕：
  - `<片名>.fr.srt` / `.fr.vtt` / `.fr.txt` — 法语
  - `<片名>.zh.srt` / `.zh.vtt` — 中文
  - `<片名>.bilingual.srt` / `.bilingual.vtt` — 中法双语
- 字幕与视频同名同目录，用 VLC / PotPlayer / MPV 打开视频即可自动加载

## 字幕为什么会脱节（v1.1.0 修复的问题）

网络视频（尤其 HLS 流）的音轨常带**时间戳断口**：某处 PTS 会直接跳空几秒，
中间没有音频包。例如本仓库测试的纪录片在 `13:51.979 → 14:00.000` 处跳空 8 秒。

如果用常规方式把音轨解码成 PCM，输出是**连续无缝**的，那 8 秒会被直接压缩掉。
于是语音识别得到的时间戳整体比视频快 8 秒——表现为：

> 前十几分钟字幕正常，之后字幕和画面越来越对不上。

v1.1.0 的处理方式：

1. 探测音轨的包时间戳，找出所有断口及其缺失秒数；
2. 解码时用 `aresample=async=1:first_pts=0` 在断口处补静音，让 PCM 时间轴与容器时间轴严格一致；
3. 校验补齐后的音频时长与视频容器时长是否相等（差值为 0 才算通过）；
4. 旧版留下的转写缓存，按断口位置做分段平移换算，不用重新识别。

实测效果（同一部 26 分钟视频，6 个分段抽检）：

| 位置 | 修复前偏差 | 修复后偏差 |
| --- | --- | --- |
| 5 分钟 | ~0 s | 0.00 s |
| 15 分钟 | **-8 s** | 0.00 s |
| 20 分钟 | **-8 s** | 0.02 s |
| 25 分钟 | **-8 s** | 0.26 s |

## 安装（只需一次）

1. 安装 Python 3.9 或更高版本（安装时勾选 **Add Python to PATH**）
   - 下载：https://www.python.org/downloads/
2. 双击运行 `install.bat`
   - 自动安装依赖库、准备 ffmpeg、预下载翻译与语音模型
   - 中途会问是否现在下载语音模型（约 1.5 GB），选 `Y` 之后就能全离线使用

> 也可以手动预热：`python install_warmup.py`（加 `--no-whisper` 可跳过 1.5 GB 大模型）


## 使用

### 图形界面（推荐）

```
python app.py
```

粘贴 france.tv 网址 → 选字幕类型和画质 → 点「开始」→ 等进度条走完。

### 命令行

```
python france2subs.py "https://www.france.tv/..."
```

常用参数：

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--subtitle` | `fr` / `zh` / `bilingual` / `all` | `bilingual` |
| `--max-height` | 视频最大高度（1080/720/540/360） | `1080` |
| `--out` | 输出目录 | 当前目录 |
| `--model` | 语音模型名 | `large-v3-turbo` |
| `--skip-download` | 跳过下载，只给已有 mp4 配字幕 | 关闭 |
| `--video` | 已有视频文件路径（配合 `--skip-download`） | — |
| `--retranscribe` | 忽略转写缓存，重新识别 | 关闭 |

示例：只给已经下好的视频配双语字幕

```
python france2subs.py "任意占位" --skip-download --video "我的视频.mp4" --subtitle bilingual
```

## 常见问题

**Q：转写很慢？**
正常。语音识别在本机 CPU 上跑，26 分钟的视频约需 5~10 分钟（视 CPU 而定）。

**Q：中文翻译有些词不对？**
翻译用本地离线模型，对地名、人名、方言的翻译可能有误差，属于离线方案的正常水平。法语字幕本身（语音识别）通常更准确，可优先看。

**Q：字幕中段开始和画面对不上？**
v1.1.0 已修复，原因是音轨时间戳断口被压缩。如果你用的是旧版，删掉 `.france2subs_work` 目录里的转写缓存重跑即可，日志里会打印断口位置和校验结果。

**Q：日志里出现「检测到 N 处音轨断口」是什么意思？**
说明这个视频的音轨本身在某几秒没有音频数据（源站的问题）。程序已自动补静音对齐时间轴，那几秒画面不会有声音，属正常现象。

**Q：提示找不到 ffmpeg？**
重新运行 `install.bat`；它已把 ffmpeg 备好，脚本会自动定位。

**Q：下载报错？**
france.tv 的部分内容有地区限制（仅法国 IP 可看）。若下载失败，通常是该视频在你的网络区域不可用。
